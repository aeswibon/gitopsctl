# Security Policy

## Supported Versions

Currently, GitOpsCTL is in early development. Only the `main` branch and the latest release tag are actively supported with security updates.

## Reporting a Vulnerability

Security is taken very seriously. If you discover a security vulnerability within GitOpsCTL, please do **not** open a public issue.

Instead, please report it via one of the following methods:

1. **GitHub Security Advisories**: If enabled on this repository, you can privately report a vulnerability by going to the **Security** tab, clicking **Advisories**, and selecting **Report a vulnerability**.
2. **Direct Contact**: If GitHub Security Advisories are not available, please contact the repository owner directly via the contact information provided in their GitHub profile.

We will review all reports and do our best to acknowledge the issue within 48 hours and provide a timeline for a fix.

### What to include in your report

Please include as much detail as possible to help us reproduce and fix the issue quickly:
- Description of the vulnerability.
- Steps to reproduce.
- Potential impact.
- Any suggested mitigations.

Thank you for helping keep GitOpsCTL secure!
